# TOOLS.md — Ecosistema de herramientas

## Available Tools (Zapier Stack)

Las integraciones se orquestan mediante Zapier MCP. Usa únicamente acciones habilitadas y consulta el esquema vigente antes de invocarlas; la disponibilidad puede cambiar.

- **Google Docs** — integración conectada y probada. Se han usado acciones para crear, leer y corregir documentos. Casos de uso: resúmenes de tarot como reflexión simbólica, bitácoras de aprendizaje y notas de proyectos.
- **Google Calendar** — integración conectada y probada. Se han usado acciones para buscar y crear eventos. Casos de uso: bloques de estudio, entrevistas, preparación y recordatorios de enfoque.
- **Telegram** — integración prevista, pero la conexión y las acciones no están verificadas. No afirmes que puedes enviar mensajes hasta confirmar una acción habilitada, autenticación y destinatario/canal.

Este catálogo puede ampliarse al conectar nuevas aplicaciones o habilitar acciones. No deduzcas que una integración está operativa solo porque aparezca aquí.

## Tool Descriptions & Capabilities

### Google Docs

Usa las acciones habilitadas para crear, actualizar, leer y verificar documentos, respetando el esquema actual.

Casos de uso sugeridos:

- Crear resúmenes de tarot presentados como reflexión simbólica, no como predicciones garantizadas.
- Mantener bitácoras de aprendizaje del curso intensivo de IA.
- Redactar y organizar notas de proyectos, preparación de entrevistas, currículums y cartas de motivación.

Antes de modificar, identifica el documento correcto. Envía el contenido completo en los campos requeridos y vuelve a leerlo para comprobar el resultado.

### Google Calendar

Usa las acciones habilitadas para buscar eventos y crear o gestionar eventos cuando la acción correspondiente esté disponible.

Casos de uso sugeridos:

- Programar bloques de estudio para 4Geeks Academy.
- Agendar entrevistas de trabajo y tiempo de preparación.
- Organizar recordatorios de enfoque como apoyos prácticos.

Incluye título, fecha, hora de inicio y fin, zona horaria y ubicación cuando corresponda. Verifica la zona horaria local y el evento creado. No presentes un ritual simbólico como garantía de resultados.

### Telegram

Si se confirma que Telegram está conectado y existe una acción habilitada para enviar mensajes, puede utilizarse para alertas solicitadas, como recordatorios matutinos o avisos relacionados con la búsqueda de empleo.

Antes de enviar, verifica el destinatario o canal y el contenido. No envíes alertas no solicitadas ni compartas datos privados con grupos o terceros. Si la conexión o el destino no están confirmados, pide el dato necesario o informa que el envío no está disponible.

## Execution Protocols

1. **Descubre antes de ejecutar.** Comprueba las acciones Zapier disponibles y consulta el esquema vigente de la acción exacta.
2. **Valida los datos.** Completa los campos requeridos con formatos válidos. Para fechas y horas, confirma la zona horaria; para documentos y mensajes, revisa el texto y el destino.
3. **Respeta el alcance solicitado.** Usa solo la cuenta, documento, calendario, chat o destinatario previsto. No inventes conexiones, permisos ni resultados.
4. **Aclara datos esenciales que falten.** No adivines cuenta, calendario, zona horaria o destinatario cuando hacerlo pueda causar un efecto externo no deseado.
5. **Detén acciones críticas.** Solicita confirmación explícita antes de cambios drásticos o masivos en calendarios, envíos masivos o eliminación de información, conforme a `AGENTS.md`.
6. **Verifica cada escritura.** Tras crear o editar, vuelve a consultar el documento o evento si hay una acción de lectura disponible. Para mensajes, informa solo del resultado confirmado por la herramienta.
7. **Sé transparente ante fallos.** Si una acción falta, la autenticación falla o la respuesta no confirma el resultado, no afirmes que se completó; explica el bloqueo y el siguiente paso.
8. **Amplía el ecosistema con control.** Añade integraciones y capacidades solo después de comprobar conexión, acciones y permisos. Actualiza este archivo sin eliminar información relevante.
